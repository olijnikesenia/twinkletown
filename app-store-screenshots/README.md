# App Store screenshots

Captured from the running app using Device Hub's native Screenshot action; the final iPad Awards frame was captured directly with simctl after Device Hub lost its window.

- iPhone 18 Pro Max: 1320 × 2868, portrait.
- iPad Pro 13-inch: 2064 × 2752, portrait.
- Locale: English (U.K.), app version 1.0.
- The simulator launch cache selects the native game for capture; game rewards and progression are earned through gameplay.
- Up to 10 screenshots per display set are uploaded; extra captures remain in `extras/`.
